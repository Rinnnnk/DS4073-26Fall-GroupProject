# B · 噪音举报

现版三个任务的图表代码在 [visualizations.R](visualizations.R)，说明与布局在 [Dashboard.Rmd](../Dashboard.Rmd)。

- B1 比较五个行政区的噪音举报构成和每千人举报率，并用箱线图查看同一行政区内部的普查区差异。
- B2 用星期 × 小时热力图比较不同举报类型的高发时段。
- B3 比较全年各月的日均举报量和夜间占比，再用行政区 × 月份散点图检查 8 月到 9 月的变化是否在五个行政区都出现。

## 可深化

说明月长和星期出现次数的标准化。可继续比较不同月份的类别增量，以及哪些类别带动了夜间占比变化。D 和 E 使用的夜间指标以 22:00 至次日 06:00 前为口径。
