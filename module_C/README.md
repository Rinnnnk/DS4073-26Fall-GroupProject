# C · 报案与轨道交通

三个任务的图表代码在 [visualizations.R](visualizations.R)，说明与布局在 [Dashboard.Rmd](../Dashboard.Rmd)。C1 和 C2 各有三张图：地图独占一行，其余两图并排一行；C3 两图并排，共五行八图。

展示材料：[Part_C_Presentation.pptx](Part_C_Presentation.pptx)（六页，沿用提供的模板；封面之外完整展示 Dashboard 的八张图；每张内容页底部有三张演讲提示卡）和 [Part_C_Speech.md](Part_C_Speech.md)（约三分钟、少数字的英文讲稿）。PPT 使用 Dashboard 图表的高清截图，以保证不同演示软件中的显示一致；交互操作仍在 Dashboard HTML 中进行。[presentation_scatter.R](presentation_scatter.R) 可单独重绘 C3 的静态散点图。Dashboard 的 C 页只保留图表标题与简短交互控件，详细解释和图表口径放在展示材料及本说明中。

- C1：普查区地图用顺序色阶定位每千人 NYPD 报案率；100% 堆叠柱图比较五区 felony、misdemeanor、violation 的构成；箱线图比较各区内部普查区报案率的中位数、四分位区间与离群点。事件时间是 2024 年，报案率只对 ACS 人口至少 500 的普查区计算。箱线图使用 log1p 位置，坐标刻度仍以每千人报案数标注。
- C2：站距地图定位远离轨道交通的普查区，橙色点表示车站综合体；五条累计曲线比较各区在给定站距内的普查区占比；横向点图列出站距最远的十个有人居住普查区及最近车站。地图与曲线纳入所有有站距的普查区，排名图另要求 ACS 人口至少 500。距离是普查区内部代表点至最近车站的直线距离，不是步行时间。
- C3：散点图按行政区着色，查看每区站距与每千人报案率的关系。点击散点或图例后，右侧分组图聚焦该普查区所属行政区；“Show all”恢复五区对比。右图在 0–399、400–799、800–1599、1600 米以上四组中展示完整行政区样本的中位数及四分位区间，悬停可查每组样本数。少于五个普查区的组不显示。C3 同时要求有效的站距和报案率。

## 图表设计与解读边界

地图用位置和顺序色阶寻找空间集中区；100% 堆叠图用共同总量比较类别比例；箱线图表达区内差异与离群点；累计曲线让任意距离阈值下的覆盖率可读；横向排名图直接指出远站普查区；散点图保留普查区差异；中位数和四分位区间同时表达典型水平与组内分散程度。五区颜色在各图间保持一致。

报案数据衡量的是记录位置和报案活动，不等于居民遭遇犯罪的风险。通勤人口、访客、站点周边活动和其他地区差异都可能影响关系，因此 C3 只作描述性比较，不能推断轨道交通对报案率的因果作用。Dashboard.Rmd 中的数值解读来自仓库当前的 `data/tracts.csv`，更新数据后须重新核对。
