# D · 同区同价

现版三个任务的图表代码在 [visualizations.R](visualizations.R)，说明与布局在 [Dashboard.Rmd](../Dashboard.Rmd)。

- D1 用联动散点图和地图比较租金与夜间举报率，并核验封顶与极端值的影响。
- D2 比较高租金普查区的多指标特征，以及各行政区的夜间举报率分布。
- D3 对比一组同区、租金相差不超过 100 美元但夜间举报率反差大的案例。

## 可深化

建议把 D2 深化为所有合格同区近价配对的差距分布，再把 D3 选例放回分布解释。比较 50、100、150 美元门槛，并标注一个区可出现在多个配对里。
