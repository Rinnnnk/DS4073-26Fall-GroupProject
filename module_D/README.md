# D · 同区同价：租金差不多的地方，其他条件差多少

三个任务的图表代码在 [visualizations.R](visualizations.R)，页面文案与布局在 [Dashboard.Rmd](../Dashboard.Rmd) 的 `Rent & Noise` 页。

- **D1** 用联动散点图和地图看租金与夜间举报率的整体关系：点击散点定位到地图，判断"租金高是否就一定更安静"。
- **D2** 把同行政区、租金中位数相差不超过 100 美元的普查区两两配对（88,183 对，覆盖 2,080 个区），比较夜间举报率、NYPD 报案率和到站距离的差距分布；再用 50 与 150 美元门槛重复一次，检查结论是否依赖门槛。
- **D3** 从配对里挑一个"差距在 90 分位、但站距差距普通"的代表对，把它放回整体分布，再用小时曲线说明差距集中在一天中的什么时段。

## 口径与实现

- 配对：`pair_gaps(d, threshold)` 在同一个 `borough` 内自连接，保留 `a < b` 保证每对只出现一次；排除 `is_top_coded(rent)`（ACS 里 3501 代表 $3,500+，真实差距未知）。
- 夜间：沿用 `scripts/prepare.R` 的窗口 `hour >= 22 | hour < 6`，与全站一致。
- 三条 ECDF 把各自的差距除以该指标自己的中位数（1 倍 = 该指标的典型差距），因为"每千人举报数"和"米"不能放在同一条原始坐标轴上；图例与悬停仍给出原始中位数。
- 选例：`pick_example()` 取夜间差距最接近 90 分位、站距差距落在四分位区间内、双方租金在 $1,200–2,600 之间的一对——代表性优先，不取极端值。
- 页面正文的数字来自 `dp <- attr(charts[[4]], "summary")`，即 `pair_summary()` 的返回值，所以图和字不会各说一套；`scripts/analysis.R` 未改动。

## 结果速查（2024 年，$100 门槛）

| 指标 | 中位差距 | 90 分位差距 |
| --- | --- | --- |
| 夜间 311 举报率（每千人） | 16.9 | 61.7 |
| NYPD 报案率（每千人） | 25.0 | 101.3 |
| 到最近车站直线距离 | 442 m | 2,589 m |

- 15.2% 的配对夜间举报率相差 ≥ 50（每千人），29.2% 的配对站距相差 ≥ 1 km。
- 门槛换成 50 或 150 美元时，中位数与 90 分位几乎不动（16.9→16.9、61.7→61.7），结论不依赖门槛。
- 代表对：Brooklyn 的 Canarsie（`36047101200`，$1,679，夜间 7.1）与 Crown Heights South（`36047021300`，$1,683，夜间 68.8）——租金差 4 美元，夜间举报率差 9.7 倍；小时差距集中在 21:00–23:00，44% 落在 22:00–05:59 窗口内。

## 限制（页面上也要说）

- 配对彼此不独立：一个普查区最多出现在 211 个配对里，所以只描述分布，不做显著性检验。
- 311 举报记录的是"有人打电话"，不是实测噪音；NYPD 报案同理，受报案意愿影响。
- 站距是普查区质心到最近车站的直线距离，不反映步行路网或班次。
